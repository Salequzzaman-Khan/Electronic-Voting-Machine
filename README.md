# Electronic-Voting-Machine

The goal of this voting system is to provide a group of individuals with the number of "yes" votes and the number of "no" votes on a topic of interest at the same time.When a group of people is gathered and it is necessary to quickly determine opinions (for or against), make decisions, or vote on certain subjects or other matters, this type of method can be employed.  At each assembly point, there is a switch for selecting "yes" or "no," as well as a digital display for the number of yes votes and one for the number of no votes in this project. Furthermore, this approach facilitates voting. Because a large number of people can vote, the majority can be easily ascertained.
